# 📦 국립공원 굿즈 바코드북

**무인샵에서 제품에 바코드가 없을 때, 폰 화면의 바코드를 계산대 스캐너로 찍기 위한 웹.**
로그인 없음, 설치 없음. 모바일 기준으로 만들었습니다.

- **주소:** https://npp-ubt.com/barcode/
- **관리자용 데이터 갱신:** https://npp-ubt.com/barcode/update.html

## 쓰는 법 (무인샵)

1. 주소를 열고 **제품명을 검색**합니다. 초성도 됩니다 (`ㅂㄷㅇ` → 반달이).
2. 나온 카드를 누르면 바코드가 뜹니다.
3. **`🔍 크게 보기 (계산대 스캔용)`** 를 누르면 흰 배경 전체화면으로 바뀌고,
   바코드가 **90도 돌아 화면 세로 길이만큼** 커집니다. 이 상태로 스캐너에 대고 찍습니다.
4. 잘 안 찍히면 **폰 화면 밝기를 최대로** 올리세요.
5. `✕` 를 누르면 상세로, 한 번 더 누르면 목록으로 돌아갑니다.

목록은 **상품명 `()` 포함 가나다순**(`(골)` → `(금)` → … → 괄호 없는 항목)으로 정렬됩니다.
단종(`사용불가`/`사용중지`) 상품은 잘못 찍는 것을 막기 위해 기본으로 숨겨져 있습니다.

## 그 밖의 기능

- **바코드 스캐너 입력** — PC에서 검색창에 포커스를 두고 스캔하면(스캐너가 Enter를 보냄) 해당 상품 상세가 바로 열립니다.
- **인쇄** — 헤더의 `🖨️ 인쇄`는 지금 화면에 걸러진 결과를 A4 3열 바코드북으로 출력합니다.
  (분류나 검색으로 걸러낸 뒤 인쇄하면 필요한 것만 나옵니다.)

## 데이터 갱신

원본은 포스에서 뽑은 **상품조회 엑셀**(`바코드북.xls`)입니다.

1. 포스에서 상품조회 엑셀을 받는다 (`No. / 상품코드 / 상품명 / 대분류 / 바코드 / … / 판매단가` 머리글).
2. [update.html](update.html)에 그 파일을 끌어다 놓는다.
3. 만들어진 `data.js`를 내려받아 `barcode/data.js`에 덮어쓴다.
4. 커밋 후 `main`에 푸시하면 GitHub Actions가 배포한다 (1~2분).

`data.js`는 자동 생성 파일이라 직접 손대지 않습니다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 조회 화면 |
| `app.js` | 검색 · 필터 · 정렬 · 상세 · 인쇄 |
| `style.css` | 스타일 (화면 + A4 인쇄) |
| `data.js` | 상품 데이터 (자동 생성) |
| `update.html` | 엑셀 → `data.js` 변환 (관리자용) |

## 데이터 형식

```js
window.BARCODE_DATA = {
  updated: '2026-08-31',        // 원본 엑셀 기준일
  source: '바코드북.xls',
  items: [
    {
      n: 1,                     // 원본 엑셀의 No.
      code: '000220',           // 상품코드
      name: '(골)반달이 가방걸이',
      grp: '골',                // 상품명 앞 괄호 = 공급/분류 구분 (필터 칩)
      bc: '8809642670075',      // 바코드 (없으면 '')
      fmt: 'EAN13',             // EAN13 | CODE128 | '' (체크디지트로 자동 판별)
      price: 11000,             // 판매단가
      dis: true,                // 선택 — 사용불가/사용중지 상품
    },
  ],
};
```

## 참고

- `index.html`의 `style.css?v=3` / `app.js?v=3` / `data.js?v=3` 뒤 숫자는 **캐시 무효화용**입니다. GitHub Pages가 파일을 10분간 캐시하므로, 이 파일들을 고친 뒤에는 숫자를 하나 올려야 직원 브라우저에 바로 반영됩니다.

- 바코드는 [JsBarcode](https://github.com/lindell/JsBarcode), 엑셀 파싱은 [SheetJS](https://sheetjs.com)를 CDN으로 씁니다. 사내망에서 이 두 CDN이 막히면 바코드가 그려지지 않습니다.
- 13자리 숫자 중 EAN-13 체크디지트가 맞는 것만 `EAN13`으로, 나머지(의류 SKU 등)는 `CODE128`로 그립니다.
- 로컬 확인: `npx serve -l 3458 barcode` 후 http://localhost:3458
